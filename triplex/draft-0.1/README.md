# MMUCO ORION Triplex: draft 0.1

> **Not an approved design, construction drawing or compliance document.**

**No Triplex draft 0.1 has been issued.** This folder holds scratch work only, in [`scratch_NOT-ISSUED/`](scratch_NOT-ISSUED/).

- **What the Triplex is:** three spatial nodes:
  1. the Orion Duplex housing;
  2. a shared public garden;
  3. a shared patio and walkway.

  It is **not** three dwellings or three storeys.
- **Develops from:** duplex **Draft 0.2.2** (issued), which is the housing node and is unchanged. The proposed Draft 0.2.3 (not issued) is not used.
- **Duplex open questions:** OQ-01 and OQ-05 to OQ-07 remain open and carry over unchanged, because the housing node is unchanged.
- **Scratch contents:**
  - the gate report;
  - the inventory and staged build plan;
  - the provisional compound parameters;
  - a 2D backyard concept DXF with checks and preview;
  - a 2D basement concept DXF for **proposal D21** (not approved), with checks and previews. D21 is one habitable basement under each dwelling. It would change the duplex housing, so it is not applied to Draft 0.2.2; it needs an option study and a new housing draft.

  No 3D model has been built yet.
- **Publication:** the scratch folder is a cleaned copy of a private working folder. `scratch_NOT-ISSUED/CLEANING_RECORD_NOT-ISSUED.md` lists what was removed, and `scratch_NOT-ISSUED/cleaned-copy-crosswalk_2026-10-25.tsv` maps each original file to its copy.
- **Not frozen:** nothing here is frozen. On issue, a draft gets its own `orion-triplex_draft-0.1_manifest.sha256`, which is then added to `tools/verify-orion.sh`.

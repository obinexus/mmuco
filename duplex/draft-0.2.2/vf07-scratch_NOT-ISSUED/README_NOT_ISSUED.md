# SCRATCH: NOT ISSUED (VF-07 kitchen-side nib investigation)

Nothing in this folder is a deliverable, an issue or an approved design. These are working files for the VF-07 option study. The issued Draft 0.2.2 is in the parent folder, listed in `MMUCO_ORION_Duplex_Draft_0.2.2_Manifest.sha256`. It was not opened for editing and was not changed.

The measured comparison, option table and evidence are in `../MMUCO_ORION_Duplex_Draft_0.2.2_VF07_Investigation/`.

| File | What it is |
|---|---|
| `WORKING_COPY_from_Draft_0.2.2.dxf` | Byte-identical copy of the issued `MMUCO_ORION_Duplex_Draft_0.2.2.dxf` (SHA-256 2ec8d3f3…). It was opened in CADCraft as the starting point for each option and never saved over (hash checked at the end) |

| `VF07_OPTION_C2_unequal_pair.dxf` | Option C2: pocket removed, 1,250 structural opening x 850–2,100, 826 + 350 pair opening into the kitchen |
